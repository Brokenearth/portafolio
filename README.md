# Portafolio — Johan Deivy Hernández Basallo

Portafolio técnico bilingüe (Español / Inglés) enfocado en **Ingeniería de Software Full-Stack y Arquitectura de Sistemas**. Construido con Astro 5, React 19 (islas interactivas en TypeScript), Tailwind CSS v4 y Vitest.

## Proyectos destacados

- **UniSport** — Monolito Modular en .NET 10 (Clean Architecture) + PostgreSQL por esquemas + Angular 22 + 1,255 pruebas automatizadas en Azure Pipelines.
- **Contratos Rurales por Voz (EasyContractField)** — Compilación léxica/sintáctica con AFD propios, Autómata a Pila y Máquina de Turing en TypeScript.
- **HAR Classifier (UCI HAR)** — Clasificación de señales inerciales en PyTorch (`Conv1D+LSTM` vs `LSTM`) con validación cruzada por sujeto sin *data leakage*.
- **Teje Ideas** — Sitio web comercial en producción para emprendimiento real.

## Desarrollo local

```bash
npm install
npm run dev
```

## Verificación

```bash
npm run typecheck
npm run test
npm run build
```

## Despliegue

El repositorio incluye configuración lista para conectar en un clic con **Netlify** (`netlify.toml`) o **Vercel** (`vercel.json`).
